Smart Budget Analyzer API

A Spring Boot-based REST API to track daily transactions and manage monthly budgets. The system allows users to record expenses/income, set budget limits, and automatically check whether they are exceeding their budget.


Add income and expense transactions
View all transactions
Set monthly budget limits
Automatic expense calculation
Budget status check (Within Budget / Exceeded)
